## 🛠️ Real In-Browser Client-Side PDF Studio

The Anything website doesn't just show simulations — it includes an **active, real client-side PDF engine** powered by [`pdf-lib`](https://pdf-lib.js.org/) and WebAssembly:

```
┌────────────────────────────────────────────────────────┐
│  USER BROWSER (100% Client-Side WebAssembly Memory)     │
│  - Draw Signature Canvas ──────┐                       │
│  - Drop Real User PDF ─────────┼──► pdf-lib Engine ──► Real .PDF Download
│  - Select Merge PDF Queue ─────┘   (Zero Servers)      (Instant)
└────────────────────────────────────────────────────────┘
```

1. **Real PDF Creator & Signer**: Synthesizes a new vector PDF document, embeds your hand-drawn signature PNG, and triggers an instant browser download.
2. **Real PDF Watermarker**: Stamps custom text (`CONFIDENTIAL · SOVEREIGN`) across all pages of your uploaded PDF.
3. **Real PDF Merger**: Combines two or more uploaded PDFs into one consolidated file.
4. **All Processing Local**: Zero megabytes uploaded to cloud servers.

## 🚀 Quick Start & Development Guide

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **Package Manager**: npm or pnpm
- **Operating System**: Windows 10 / Windows 11 (64-bit recommended)

### 1. Clone & Install
```bash
git clone https://github.com/BSFrameWorks5253/Anything.git
cd Anything/Anything_Website
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to experience the liquid glass parallax interface.

### 3. Build Production Bundle
```bash
npm run build
```
Compiles optimized static assets to `dist/` with zero TypeScript lint errors.
